## 🚀 Getting Started

### 1) Clone

```bash
git clone https://github.com/ahmadgill7/3d-portfolio-website.git
cd 3d-portfolio-website
```

### 2) Install

```bash
npm install
```

### 3) Run locally

```bash
npm run dev
```

### 4) Build

```bash
npm run build
```
